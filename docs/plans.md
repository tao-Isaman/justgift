# แพ็กเกจ Just Gift

> **ทุกแพ็กเกจไม่หักค่าธรรมเนียมโดเนท (0%)** — เงินโดเนทเข้าบัญชีสตรีมเมอร์โดยตรง
> แพ็กเกจปลดล็อกเฉพาะฟีเจอร์เท่านั้น

## เปรียบเทียบแพ็กเกจ

| ฟีเจอร์ | ฟรี | อีลิท |

| รับโดเนทพร้อมตรวจสลิป (RDCW) | ✓ | ✓ |
| **จำนวนโดเนท/เดือน** | **ไม่จำกัด** | **ไม่จำกัด** |

| ใส่ภาพ / GIF แจ้งเตือนเอง | – | ✓ |

## สรุปแต่ละแพ็กเกจ

### 🆓 ฟรี — ฿0
รับโดเนทได้ครบ ไม่จำกัดจำนวน
- รับโดเนทที่ตรวจสลิปกับธนาคารแล้ว **ไม่จำกัดครั้ง/เดือน**
- Overlay OBS เรียลไทม์ + ประวัติการโดเนท
- แจ้งเตือนสไตล์เริ่มต้น (ปรับแต่งไม่ได้ + มีลายน้ำ Just Gift)

### 👑 อีลิท — ฿199/เดือน
ปลดล็อกทุกฟีเจอร์ ปรับแต่งได้เต็มที่
- ทุกอย่างในแพ็กฟรี + ไม่มีลายน้ำ
- ปรับสี / ฟอนต์ / เสียง และใส่ภาพ / GIF แจ้งเตือนเอง
- อ่านข้อความเป็นเสียงภาษาไทย (TTS) + ตั้งยอดโดเนทขั้นต่ำ
- เป้าหมายโดเนท + ลีดเดอร์บอร์ด
- แชร์มีเดีย (คลิปขึ้นจอ) + สไตล์แจ้งเตือนหลายแบบ
- ซัพพอร์ตแบบเร่งด่วน

## สถานะการพัฒนา (โน้ตภายใน)
- ✅ โครงสร้างสองแพ็กเกจ: **ฟรี / อีลิท** (ตัดแพ็กโปรออก)
- โควต้าโดเนท/เดือน: **ไม่จำกัดทั้งสองแพ็ก** — ต้นทุนค่าตรวจสลิปออกแบบให้ชดเชยด้วยทิปฝั่งผู้โดเนท ไม่ใช่การจำกัดผู้ใช้ฟรี
- ฟรีต่างจากอีลิทตรง "แก้ไขหน้าตาการแจ้งเตือนไม่ได้ + มีลายน้ำ"
- หมายเหตุ: ค่า `PLAN_DONATION_LIMIT` ยังเป็น knob เผื่อใส่ soft cap กันการใช้งานผิดปกติภายหลังได้
