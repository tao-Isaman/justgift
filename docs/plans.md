> แพ็กเกจปลดล็อกเฉพาะฟีเจอร์เท่านั้น

## สรุปแต่ละแพ็กเกจ

### 🆓 ฟรี — ฿0
ทุกอย่างที่จำเป็นสำหรับเริ่มรับโดเนท
- รับโดเนทที่ตรวจสลิปกับธนาคารแล้ว
- Overlay OBS เรียลไทม์ + ประวัติการโดเนท
- แจ้งเตือน 1 สไตล์ (มีลายน้ำ JustGift)

### 🔥 โปร — ฿99/เดือน *(ยอดนิยม)*
ทำให้การแจ้งเตือนเป็นสไตล์ของคุณ
- ทุกอย่างในแพ็กฟรี
- ปรับสี / เสียง และใส่ภาพ / GIF แจ้งเตือนเอง
- อ่านข้อความเป็นเสียงภาษาไทย (TTS)
- ไม่มีลายน้ำ + ตั้งยอดโดเนทขั้นต่ำได้

### 👑 อีลิท — ฿199/เดือน
สำหรับครีเอเตอร์มืออาชีพ
- ทุกอย่างในแพ็กโปร
- เป้าหมายโดเนท + ลีดเดอร์บอร์ด
- แชร์มีเดีย (คลิปขึ้นจอ) + สไตล์แจ้งเตือนหลายแบบ
- ซัพพอร์ตแบบเร่งด่วน
